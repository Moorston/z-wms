# 系统管理深度深化分析

---

## 一、业务定义与目标

### 1.1 定义

系统管理（System Management）是WMS的基础支撑模块，提供用户、角色、权限、组织、数据字典、参数配置、日志审计、系统监控等基础功能，确保系统安全、可控、可运维。

### 1.2 核心目标

| 目标 | 衡量指标 |
|------|---------|
| 安全可控 | 权限合规率100% |
| 可追溯 | 操作日志覆盖率100% |
| 可配置 | 业务参数可配置率 >90% |
| 高可用 | 系统可用性 >99.9% |

### 1.3 业务场景全景

```
系统管理
├── 用户管理（用户档案/密码/状态/多因素认证）
├── 角色管理（角色定义/角色权限/数据权限）
├── 权限管理（菜单权限/按钮权限/数据权限/API权限）
├── 组织管理（公司/部门/班组/岗位）
├── 数据字典（15类80+项字典/可扩展）
├── 参数配置（系统参数/业务参数/仓库级参数）
├── 操作日志（登录日志/操作日志/异常日志）
├── 安全审计（敏感操作审计/权限变更审计）
├── 系统监控（服务状态/资源使用/接口监控）
├── 任务调度（PowerJob定时任务管理）
├── 消息模板（消息模板/通知配置）
├── 国际化（多语言/时区）
├── 数据备份（备份策略/恢复）
└── 系统公告（公告管理/版本发布）
```

## 三、状态机设计

用户状态：正常→锁定（密码错误超限）→禁用→正常（解锁）；定时任务状态：待执行→执行中→成功/失败→重试。

## 四、核心业务场景详解

### 4.1 用户管理

用户档案（用户名/姓名/手机/邮箱/所属组织/岗位/状态），密码策略（复杂度/有效期/历史密码/错误锁定），支持LDAP/SSO集成，多因素认证（可选）。

### 4.2 角色权限管理

RBAC模型：用户→角色→权限。角色定义（管理员/仓库主管/拣货员/复核员/客户/访客），菜单权限（页面访问）、按钮权限（操作按钮）、数据权限（按货主/仓库/组织隔离）、API权限（接口访问）。

### 4.3 数据字典

15类80+项字典：单据类型、状态、库存状态、库位类型、质检类型、快递商、计费项目、作业类型、设备类型、异常类型等。支持自定义字典，字典项可启用/禁用/排序。

### 4.4 参数配置

系统参数（全局）、业务参数（按仓库/货主）：波次参数、上架规则、分配规则、预警阈值、超时时间等。参数变更记录审计日志，支持参数模板。

### 4.5 操作日志

登录日志（登录时间/IP/设备/结果）、操作日志（操作人/时间/模块/操作/前后值/IP）、异常日志（异常堆栈/请求参数）。日志不可删除，支持查询和导出。

### 4.6 安全审计

敏感操作审计（权限变更/数据删除/参数修改/库存调整），审计报表，定期审计报告。

### 4.7 系统监控

服务状态（各微服务健康检查）、资源使用（CPU/内存/磁盘/连接池）、接口监控（响应时间/成功率/限流）、告警通知（邮件/短信/消息）。

### 4.8 任务调度

PowerJob分布式调度，定时任务管理（创建/启用/禁用/手动执行/执行日志），支持工作流和MapReduce任务。

### 4.9 国际化

多语言支持（中文/英文），时区配置，消息源国际化。

## 五、库存变化分析

系统管理不直接改变库存，用户操作导致的库存变动记录在操作日志中。

## 六、技术实现方案

### 6.1 核心表设计

```sql
-- 用户 sys_user (user_id/username/password/name/phone/email/org_id/status/last_login_time)
-- 角色 sys_role (role_id/role_code/role_name/role_type/status)
-- 权限 sys_permission (perm_id/perm_code/perm_name/perm_type/parent_id/url/icon/sort)
-- 用户角色 sys_user_role (user_id/role_id)
-- 角色权限 sys_role_permission (role_id/perm_id)
-- 数据权限 sys_data_permission (role_id/scope_type/scope_value)
-- 组织 sys_org (org_id/org_code/org_name/org_type/parent_id/sort)
-- 数据字典 sys_dict_type (dict_id/dict_code/dict_name/status)
-- 字典项 sys_dict_item (item_id/dict_id/item_code/item_value/sort/status)
-- 参数 sys_config (config_id/config_key/config_value/config_type/remark)
-- 操作日志 sys_operation_log (log_id/user_id/module/operation/method/params/ip/created_at)
```

### 6.2 权限校验

Spring Security + JWT认证，网关层统一鉴权，服务内方法级权限注解（@PreAuthorize），数据权限通过MyBatis拦截器自动拼接warehouse_code/owner_code条件。

## 八、常见业务问题与解决方案

| 问题 | 解决方案 |
|------|---------|
| 权限混乱 | RBAC标准化+最小权限+定期审计+权限模板 |
| 数据泄露 | 数据权限隔离+敏感加密+操作审计+访问控制 |
| 密码安全 | 密码策略+多因素认证+定期更换+锁定机制 |
| 系统性能 | 监控告警+限流降级+资源扩容+性能优化 |
| 日志丢失 | 异步写入+多副本+定期备份+不可篡改 |
| 参数误改 | 审批流程+变更记录+回滚+权限控制 |
