# X WMS 业务模块深度深化文档总览

## 文档说明

本文档集是 X WMS 企业级仓储管理平台的业务模块深度深化分析，每个模块均按照统一的 **9段式结构** 进行深度拆解，达到开发实施级别的详细程度。

**统一9段式结构：**
1. 业务定义与目标
2. 业务流程图（Mermaid）
3. 状态机设计（状态+流转+触发条件）
4. 核心业务场景详解（正常+异常）
5. 库存变化分析（每个动作的库存影响）
6. 技术实现方案（表设计/核心逻辑/伪代码）
7. 主流WMS对比（富勒/曼哈特/Blue Yonder）
8. 常见业务问题与解决方案
9. 与其他模块的关联关系

## 技术架构决策（已确认）

| 决策项 | 选型 | 说明 |
|--------|------|------|
| 微服务数量 | 4个（core/base/analytics/integration） | 否决13微服务，降低成本 |
| 库存扣减 | Oracle 23ai直接扣减 | 否决Redis分桶扣减，原子SQL+乐观锁 |
| Redis用途 | 库存检查/预占/缓存/限流 | 不做库存扣减 |
| 消息队列 | Kafka 4.3 KRaft + Redis List混合 | 高吞吐用Kafka，简单队列用Redis |
| 数据库 | Oracle 23ai（核心）+ ClickHouse 25.8（OLAP） | 不分库分表，核心不读写分离 |
| 搜索引擎 | 不引入Elasticsearch | Oracle全文索引+ClickHouse满足 |
| 调度 | PowerJob 4.3.4 | 分布式任务调度 |
| 限流降级 | Resilience4j 2.3.0 | 轻量级熔断限流 |
| 流程编排 | LiteFlow 2.16.1.2 | 入库/波次/库存分配流程 |
| 状态机 | 自研轻量级状态机 | 5个核心状态机 |
| 部署 | Docker Compose + K3s可选 | 否决完整K8s，低成本优先 |
| 技术栈版本 | Java 25 + Spring Boot 4.1 + Spring Cloud 2025.1.2 | 全量最新LTS版本 |
